# Repository topics

GitHub topics make software easier to find and help downstream systems classify projects.

## Required baseline

- `research-software`
- `netherlands-escience-center`
- `open-science`
- `fair-software`

## Add domain topics

Examples:

- `life-sciences`
- `climate-science`
- `digital-humanities`
- `astronomy`
- `social-sciences`
- `geospatial`
- `cultural-heritage`

## Add technical topics

Examples:

- `python`
- `r`
- `javascript`
- `typescript`
- `workflow`
- `hpc`
- `machine-learning`
- `visualization`
- `dashboard`
- `api`
- `sveltekit`
- `jupyter`

## Add project-specific topics

Use names of important methods, standards, datasets, communities, or infrastructures.

Keep topics specific enough to help discovery. A topic named `software` has all the nutritional value of wet cardboard.
